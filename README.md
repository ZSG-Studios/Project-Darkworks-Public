# Project DarkWorks

Download [DarkWorks-Launcher.exe](https://github.com/ZSG-Studios/Project-Darkworks-Public/releases/latest/download/DarkWorks-Launcher.exe) on Windows x64. Open it to install and update DarkWorks, then select **Play**. The game opens with the public server selected.

The [latest release](https://github.com/ZSG-Studios/Project-Darkworks-Public/releases/latest) also includes a standalone Windows client ZIP. Extract the full ZIP and open DarkWorks.exe.

This repository distributes the Windows DX12 client and launcher.
